# Каталог Seller API для MCP

В каталоге 809 записей — 491 исходная запись Ozon, 307 Wildberries и 11 отдельно описанных замен. Из них 470 доступны для чтения и 318 для запроса на изменение. В 11 карточках приведён новый порядок действий, 10 помечены как снятые с поддержки. Числа обозначают идентификаторы MCP. Несколько идентификаторов могут обращаться к одному методу площадки.

При повторной сверке 76 записей 19 ноября 2026 года получены следующие результаты.

| Площадка | Чтение | С подтверждением | Нужен выбор преемника или новый процесс | Сняты с поддержки |
| --- | ---: | ---: | ---: | ---: |
| Ozon | 14 | 7 | 10 | 10 |
| Wildberries | 21 | 13 | 1 | 0 |

Карточка метода показывает фактический хост, HTTP-метод и схему параметров. У совместимых идентификаторов поля `legacy_route` и `alias_of` связывают прежний адрес с действующим. Вызов принимает параметры текущего API и использует его лимит. В карточках со статусом `superseded` перечислены подходящие операции и описан переход. Например, Ozon для возвратов rFBS выдаёт допустимые действия отдельно для конкретного возврата. У методов `retired` выполнение заблокировано. Основания по каждой записи приведены в [реестре сверки](review.jsonl).

Для повторной сверки использована официальная схема Ozon от 19 ноября, включая журнал отключений. У ранее выпущенных операций сохранена привязка к документу, по которому они были проверены. У методов WB используются русскоязычные OpenAPI площадки. Формирование отчёта, запуск рекламы, проверка кода курьера с записью времени и проверочный запрос Ozon на URL требуют подтверждения владельца. Поле `vendor_readonly_token` показывает совместимость с токеном WB. Даты, адреса и SHA-256 приведены в [списке источников](sources.json).

Для WB Цифровой используется архив опубликованного Wildberries файла `14-wbd.yaml`. На дату сверки прежний адрес файла возвращал HTTP 404. Публичное дерево категорий доступно через `wb_get_api_catalog`. Авторские операции используют отдельный токен WB Цифровой, который настраивается в разделе «Операции маркетплейсов». Площадка дополнительно согласует право удаления ключей активации. В списках ключей MCP показывает идентификаторы и даты, значение одноразового кода скрыто. При скачивании файла MCP принимает URI из данных своего контента и возвращает диапазоны до 360 КиБ. ## Использование

В настройках кабинета создайте ключ «Полный каталог Ozon и WB» с правами чтения либо с дополнительным правом предлагать изменения. Недавний вход по письму требуется для выдачи этих прав. Подключите клиент к `https://3dprinta.shop/mcp`. При OAuth для предложений нужны `mcp:read mcp:propose`. Ключи ранее подключённых приложений сохраняют свои права.

1. `market_api_search` находит операции по названию и пути. Для следующей страницы передайте `next_offset` в поле `offset`.
2. `market_api_describe` возвращает схему конкретной операции, обязательные поля, дату и источник. Например, `wb_fbs_warehouses` читает склады продавца.
3. `market_api_read` принимает `{"operation_id":"wb_fbs_warehouses","input":{}}`. Параметры пути, запроса, заголовки и тело передаются в `path`, `query`, `header` и `body`. При ответе с данными покупателя доступ ограничивает отдельный ключ полного каталога.
4. `market_api_propose` сохраняет параметры изменения и принимает устойчивый `request_id` длиной от 16 символов. Владелец видит приложение, операцию и параметры в разделе «Операции маркетплейсов». После подтверждения результат доступен через `market_api_status`. Приложение может проверять только свои запросы.

У предложения 15 минут на подтверждение. Запись о неизвестном результате сохраняется после перезапуска. Перед повторной отправкой владелец сверяет результат с кабинетом площадки. Кнопка остановки дожидается выхода активной отправки. HTTP 202 и идентификатор задания подтверждают постановку операции в очередь. Окончательный результат асинхронного задания проверяется отдельным методом статуса.

MCP принимает до 4 МиБ на запрос с предложением, включая Base64 и метаданные файлов. Обычный запрос ограничен 64 КиБ, ответ отдельного вызова площадки — 360 КиБ. Длинные списки запрашиваются постранично по схеме метода.

## Пересборка

Сохраните документы под именами из `sources.json` в один каталог. Для архивной схемы WB Цифровой используйте закреплённый `archive_url`. Для генератора требуется PyYAML. Выполните `python tools/market-catalog/compile.py SOURCES --output services/email-auth/market_routes.jsonl`. Генератор проверяет SHA-256, официальный хост каждой исполняемой операции и ссылки на преемников.
