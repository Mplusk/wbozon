# Использование цены материала

Цена материалов хранится в `config/production.yaml`. Из-за отсутствия внешних библиотек файл записан в JSON-синтаксисе, который также является допустимым YAML: при редактировании сохраняйте именно этот синтаксис. `price_source` указывает происхождение цены и дату. Настройки из `config/production.example.yaml` автоматически не используются.

Чтобы использовать цену PLA или PETG из файла, передайте `--material PLA` или `--material PETG`, а из объекта `inputs` входного JSON удалите `plastic_rub_per_kg`. Пример с условными данными ТЗ (кроме цены материала):

```bash
python3 -c 'import json; d=json.load(open("examples/spec_7_3.json")); del d["inputs"]["plastic_rub_per_kg"]; print(json.dumps(d))' | python3 -m calc --material PLA
```

В ответе `material_input` показывает выбранный материал, цену и источник. Если `plastic_rub_per_kg` уже указан во входном JSON, выбор материала приведёт к ошибке: ни одно значение не будет незаметно заменено. Неизвестные материалы, неоднозначные записи и записи без источника отклоняются. Другие исходные данные остаются обязательными; для бизнес-решений их нужно заменить на реальные с указанием источников.

Для альтернативного файла используйте `--production /путь/production.yaml` вместе с `--material`. Без `--material` работает прежний интерфейс: укажите цену во входном JSON. Изменение конфигурации не меняет и не пересчитывает уже сохранённые результаты.
