# Локальное хранилище

`Store` хранит версии паспортов и расчёты в локальном SQLite-файле. Это прототип для разработки, а не PostgreSQL, VPS-сервис, архив, шлюз действий или механизм авторизации. Данные для PostgreSQL позже нужно будет перенести и проверить отдельно.

```python
from storage import Store

with Store("work.sqlite3") as store:
    revision_id = store.save_candidate(
        "candidate-001",
        {"stage": "idea", "idea": {"model_url": "https://example.org/model"}},
        source="https://example.org/model",
        observed_at="2026-11-12T12:00:00+03:00",
    )
    revisions = store.candidate_history("candidate-001")
    # Когда будут ВСЕ входные данные calc.calculate:
    # run_id = store.save_calculation(revision_id, inputs, source="ссылка на пакет источников",
    #                                 observed_at="2026-11-12T12:00:00+03:00")
    # runs = store.calculation_history(revision_id)
```

Каждое сохранение добавляет новую запись: предыдущее состояние не перезаписывается. Расчёт выполняется `calc.calculate`, а вместе с результатом хранятся входы, эффективные пороги, источник и время наблюдения; результаты Decimal сохраняются как десятичные строки. `observed_at` обязателен и должен содержать часовой пояс. Время сохранения фиксируется отдельно. Если у входов разные источники, `source` должен указывать на доступный пакет, в котором указан источник и дата каждого показателя. Само хранилище не проверяет достоверность ссылок или индивидуальное происхождение каждой цифры.

Секреты нельзя передавать в хранилище. Реализована лишь частичная защита от очевидных имён полей секретов и URL с параметрами; она не обнаружит все секреты в произвольном тексте. Новый файл создаётся с правами 0600, однако доступ к существующему файлу, защита каталога, резервное копирование, контроль изменений и восстановление не настроены. Прямой доступ к файлу или SQL позволяет изменять историю; записи не являются юридически подтверждёнными или защищёнными от подмены. Схема не является готовой миграцией на PostgreSQL; для повторения старых расчётов может потребоваться исходная версия кода калькулятора.
