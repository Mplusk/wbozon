# Ручной импорт кандидата

Модуль сохраняет в локальную базу ссылку на 3D-модель и известные поля паспорта. Он не открывает ссылки, не ищет модели, не проверяет авторство, условия лицензии и не решает вопрос прав. Содержимое сайта и приложенных материалов не исполняется как инструкции. Прототип не подключён к Telegram, расписанию и автоматическому поиску.

Пример с условной ссылкой (локальный файл базы должен храниться в закрытом каталоге вне репозитория):

```bash
printf '%s\n' '{"candidate_id":"demo-001","model_url":"https://example.org/models/1"}' | python3 -m scout --db /tmp/scout.sqlite3
```

Отсутствующие поля перечисляются в `blockers`; неполная запись сохраняется со стадией `idea` и с правами `unchecked`. Отсутствие оценки спроса или расчёта не скрывается. Выход 2 означает неполный паспорт, 0 — паспорт содержит поля для передачи аналитику спроса, 1 — ошибка ввода или хранения. Статус 0 не переводит стадию и не разрешает печать или публикацию.

Дополнительно в JSON допустимы `name`, `author_url`, `license`, `photo_url`, `print_profile_source`, `mass_g` (г), `print_hours` (ч) и `observed_at` (ISO 8601 с часовым поясом). Если время не указано, используется время записи в UTC, а не предполагаемая дата публикации модели. Источником для паспорта записывается `model_url`, для массы и времени — также отдельная ссылка `print_profile_source`. Передавайте только подтверждённые значения; права и подтверждения через этот ввод задать нельзя. Сведения о лицензии записываются как представлены и не являются автоматическим фильтром или подтверждением коммерческих прав.

Все URL должны быть HTTP(S), без логина, пароля, параметров, фрагмента или явного порта; это снижает риск сохранения токенов в ссылках. Источники, которым обязательны параметры, нужно документировать отдельно; модуль не изменяет URL автоматически. При повторном импорте с тем же `candidate_id` сохраняется новая версия паспорта, без автоматического объединения или поиска дубликатов. Разные источники и время наблюдения должны быть подтверждены вызывающим кодом; ссылки и даты не удостоверяются автоматически. Файл и каталог базы нужно защитить и резервировать отдельно; история SQLite не защищена от подмены.
