# Снимок списка товаров Ozon

`python3 -m collectors.ozon --output /защищённый/путь/ozon-snapshot.json`

Перед запуском отдельно настройте `OZON_CLIENT_ID` и `OZON_API_KEY` через защищённое хранилище среды с правами, необходимыми для чтения списка товаров. Не передавайте значения ключей в чат или аргументах команд. Размещайте снимок вне репозитория в закрытом каталоге: он может содержать данные кабинета. Новый файл создаётся с правами 0600 и не перезаписывает существующий.

Сборщик использует тот же фиксированный запрос к `/v3/product/list`, что и существующая проверка доступа: первая страница, лимит один товар. В снимке записаны время UTC, адрес источника и сырой JSON. `complete: false` означает, что это **не полный список**. Данных для продаж, цен, тарифов или аналитики этот модуль не собирает. Он не выполняет действия, изменяющие кабинет, и не запускается по расписанию самостоятельно.

На дату реализации официальная документация Seller API из этой среды не открылась, а подтверждённых реальных ответов кабинета нет. Перед использованием и развитием пагинации сверить контракт с [документацией Ozon Seller API](https://docs.ozon.ru/api/seller/) и проверить фактические права и ответ на тестовом доступе. Код проверен на искусственных ответах, не на реальном аккаунте.
