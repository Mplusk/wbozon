# Безопасное подключение API маркетплейсов

Здесь подготовлена проверка доступа к API Wildberries и Ozon. Пароли от личных кабинетов, коды подтверждения и доступ к кабинету ей не нужны. Ключи ещё не настроены; фактический доступ зависит от выданных ключам прав и должен быть проверен отдельно.

## Ключи

Создайте отдельный API-ключ для каждого кабинета и выдайте ему только права на чтение, нужные для работы. Для Wildberries предусмотрен запрос проверки соединения; для Ozon — чтение списка товаров с ограничением одним товаром. Выбирайте соответствующие доступные категории прав при создании ключа. Если для нужной операции нельзя ограничить права только чтением, прежде оцените фактически выдаваемые права. Дополнительные операции и права можно добавить позже, когда будут понятны задачи.

Передавайте ключи через защищённые настройки секретов среды исполнения, а не в чат, репозиторий, код, аргументы команд или скриншоты. Привяжите имена переменных:

* `WB_API_TOKEN` — API-токен Wildberries.
* `OZON_CLIENT_ID` — Client ID кабинета Ozon.
* `OZON_API_KEY` — API-ключ Ozon.

Секреты, доступные процессу, потенциально доступны и другому коду с аналогичными правами в среде; ограничение доступа к среде и её настройкам остаётся важным. `.gitignore` снижает вероятность случайной публикации файлов с секретами, но не является хранилищем секретов. Если ключ попал в чат или другое неподходящее место, отзовите его в кабинете и создайте новый.

## Проверка

Когда секреты будут настроены в среде, выполните:

```bash
python3 marketplace_check.py wb
python3 marketplace_check.py ozon
```

Скрипт выводит только результат или код HTTP, не выводит ответ API, ключи или сведения о товарах. Он обращается только к фиксированным адресам, отклоняет перенаправления и использует стандартную проверку TLS Python; системные настройки прокси при этом сохраняются. Прокси среды может проверять HTTPS-трафик с помощью своего доверенного сертификата: это означает, что ему доступны данные запроса. На стороне маркетплейсов разрешения ключей являются основным ограничением. Эти меры уменьшают риск, но не гарантируют отсутствие утечек.

Проверка тестов без секретов и сети: `python3 -m unittest`.

Официальная документация: [Wildberries API](https://dev.wildberries.ru/openapi/api-information), [Ozon Seller API](https://docs.ozon.ru/api/seller/).
