# Локальный цикл проверки

`python3 -m workcycle --db /path/to/local.sqlite < examples/workcycle_demo.json`

Команда принимает JSON на стандартном вводе: `candidate_id`, `candidate` со стадией, `source` и `observed_at` (ISO 8601 с часовым поясом); `economics` содержит `inputs` для `calc`, `source`, `observed_at`, необязательные `limits` и `material`. При `material` цена берётся из производственного файла; `plastic_rub_per_kg` в этом случае в inputs быть не должно. Укажите сводный источник, позволяющий найти каждую входную цифру, если данные взяты из нескольких мест. Цена материала и её источник дополнительно сохраняются в версии кандидата. При отсутствии входов, источников, подтверждений или непрохождении порогов возвращается `blocked` с причинами. Числовые строки результата и входы хранятся с достаточной для повторного расчёта точностью.

Пример полностью условный: ссылки ведут в несуществующий домен, прочие значения основаны на примере из ТЗ, цена материала берётся из настроек пользователя. Вывод не является проверкой спроса и не основание для запуска. В истории будут видны только сохранённые версии и успешные расчёты; входы, которые не прошли проверку, не сохраняются как результат расчёта. Команда не изменяет стадию и не обращается к Ozon, Telegram или ревизору; записи о проверках и решениях не аутентифицируются. Код возврата: 0 — локальные проверки пройдены и необходима проверка человеком, 2 — есть блокировки.
