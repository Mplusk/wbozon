# Авито в MCP 3dprinta.shop

У Авито, Ozon и Wildberries один адрес Streamable HTTP. Набор инструментов зависит от площадок, выбранных владельцем при выдаче ключа. [Адрес MCP](https://3dprinta.shop/mcp)

## Подключение

1. После входа по письму откройте раздел «Авито» в [кабинете](https://3dprinta.shop/settings). Введите Client ID и Client Secret своего приложения Avito API для бизнеса. Сохранить или заменить их можно в первые пять минут сеанса. Портал шифрует оба значения.
2. Нажмите «Проверить подключение Авито». Портал получает токен по OAuth Client Credentials, читает собственный профиль продавца и показывает результат с временем проверки. У каждого раздела API могут быть отдельные условия доступа.
3. В разделе «Подключение других ИИ» укажите название приложения и выберите «Авито» или «Ozon, Wildberries и Авито». Скопируйте созданный ключ MCP. В перечне ключей видны площадки и время последнего обращения.
4. Добавьте адрес MCP в веб-клиент, поддерживающий пользовательские удалённые MCP. При авторизации введите созданный ключ на странице 3dprinta.shop. Для клиентов, позволяющих задать заголовок, поддерживается `Authorization: Bearer <ключ MCP>`. Client Secret Авито остаётся в кабинете. Отзыв ключа прекращает доступ по нему и по выданным через него OAuth-токенам.

## Что можно прочитать

| Данные | Инструменты для начала |
| --- | --- |
| Профиль, объявления и остатки | `avito_get_user_info_self`, `avito_get_items_info`, `avito_get_item_info`, `avito_get_stocks_info` |
| Заказы, доставка | `avito_get_orders`, `avito_get_courier_delivery_range` |
| Чаты, сообщения, отзывы и рейтинг | `avito_get_chats_v2`, `avito_get_messages_v3`, `avito_get_reviews_v1`, `avito_get_ratings_info_v1` |
| Баланс, финансовые операции, расходы | `avito_get_user_balance`, `avito_post_operations_history`, `avito_account_spendings` |
| Статистика объявлений и звонков | `avito_item_analytics`, `avito_item_stats_shallow`, `avito_post_calls_stats` |
| Продвижение и автозагрузка | `avito_get_services_by_items_v2`, `avito_list_orders_by_user_v1`, `avito_get_uploads`, `avito_get_current_upload_items` |

Все 33 операции читают данные. Номер своего аккаунта сервер получает у Авито. Дробные числа приходят как десятичные строки с исходной точностью. Ответ содержит время получения, путь метода и, для постраничных выборок, параметр продолжения. Список объявлений по умолчанию охватывает активные объявления. Для чатов Авито использует тип `u2i` по умолчанию. Для выборки всех типов передайте `chat_types: ["u2i","u2u","a2u"]`.

Портал исключает структурированные личные контакты, адреса курьерской доставки и подписанные ссылки. Публичный адрес пункта выдачи в заказе доступен. Текст переписки и отзывов может содержать персональные данные и инструкции третьих лиц. История чата предоставляется как данные для анализа.

При ответе 429 сервер сохраняет паузу для метода и приложения на диске. Если срок повтора неизвестен, последующие запросы к этому методу возвращают `retry_time_unknown`. Состояние сохраняется после перезапуска и отката. Портал различает отсутствующие учётные данные, отказ в правах и ограничение частоты.

## Версии методов и хранение ключей

Список адресов из задания сверен со снимком машиночитаемой документации Avito API от 3 октября 2026 года. Для списка услуг продвижения используется `/promotion/v2/items/services/get`. Точные параметры публикуются самим MCP через `tools/list`. Во время подготовки прямой источник схемы вернул HTTP 429. [Официальный каталог](https://www.avito.ru/developers/api-catalog) · [Использованный снимок](https://github.com/MissiaL/avito-api/blob/9dac805f6887c2a21fba7a7c71e4ca6ece8d0bbc/references/avito-api-openapi.json)

Ранее выданным ключам доступны Ozon и Wildberries. Хеши ключей с доступом к Авито лежат в отдельной базе `<VAULT_PATH>.avito-keys`. Старая версия при откате не принимает эти ключи и связанные с ними OAuth-токены. При восстановлении из резервной копии нужны база авторизации, база кабинета и соответствующая база ключей из одного снимка. Контроллер сохраняет базу ключей при её наличии во время остановки приёма новых запросов.
