# Контрольный пример из раздела 7.3 ТЗ

Запуск из корня проекта:

```bash
python3 -m calc < examples/spec_7_3.json
```

Это условные значения для проверки формул, а не данные владельца, действующие тарифы маркетплейса или налоговая рекомендация. В ТЗ некоторые суммы приведены совместно. Чтобы ввести их в отдельные поля калькулятора и воспроизвести итог, использованы допущения:

- 35 ₽ на упаковку и доставку до склада распределены как 35 ₽ и 0 ₽ соответственно; ТЗ не задаёт их разбиение.
- Амортизация составляет 12 ₽/ч (60 000 ₽ / 5 000 ч); обслуживание 3 ₽/ч выведено из общей суммы 52,50 ₽ за 3,5 часа печати.
- Хранение и приёмка составляют 3 ₽: из объединённой суммы хранения и эквайринга 18,80 ₽ вычтен эквайринг 2% от цены 790 ₽.

Доли указаны десятичными числами: например, 0,25 означает 25%. Расчёт выполняется без промежуточного округления; результаты расчёта в JSON выведены десятичными строками. Минимальные цены округляются вверх до копейки.
